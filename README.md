🌌 NASA NEO (Near-Earth Object) Tracking & Insights
This project provides insights into Near-Earth Objects (NEOs) using NASA's public API. It fetches, transforms, stores, and visualizes asteroid data using Python, MySQL, and Streamlit.

🚀 Project Overview
Using data from NASA's NeoWs (Near Earth Object Web Service), this project allows users to:

Fetch real-time and historical asteroid data.

Store structured data in a MySQL database.

Analyze NEO characteristics like size, velocity, and approach distance.

Display results through a Streamlit dashboard with filters and charts.

📂 Repository Contents
NASA_NEO_project.ipynb – Jupyter notebook for development, testing, and exploratory analysis.

neo.py – Final Python script with functional logic to automate API data fetching and database insertion.

🛠️ Technologies Used
Python – Data fetching, transformation, and backend logic.

NASA API (NeoWs) – Source of asteroid data.

MySQL – Structured data storage.

Streamlit – Interactive front-end dashboard.

Pandas / Requests – Data handling and HTTP requests.

📊 Features
Daily NEO tracking based on start and end dates.

Filters for hazardous asteroids.

Velocity and size comparisons.

Interactive dashboard with visual insights.
